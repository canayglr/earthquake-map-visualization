# 🌍 Earthquake Map Visualization

![Python](https://img.shields.io/badge/Python-informational?style=flat-square) ![pandas](https://img.shields.io/badge/pandas-informational?style=flat-square) ![Basemap](https://img.shields.io/badge/Basemap-informational?style=flat-square)

**<img src="https://raw.githubusercontent.com/canayglr/canayglr/main/assets/flags/gb.png" height="14" alt="EN"/>** Loads **23,412 significant earthquakes (1965–2016)** from `database.csv`, converts date/time to timestamps with pandas and plots every epicenter on a world map with Matplotlib Basemap.

**<img src="https://raw.githubusercontent.com/canayglr/canayglr/main/assets/flags/tr.png" height="14" alt="TR"/>** `database.csv` dosyasındaki **1965–2016 arası 23.412 büyük depremi** okur, tarih/saat bilgisini pandas ile zaman damgasına çevirir ve tüm merkez üslerini Matplotlib Basemap ile dünya haritası üzerinde gösterir.

## Run / Çalıştırma
```bash
pip install pandas matplotlib basemap
python index.py
```
